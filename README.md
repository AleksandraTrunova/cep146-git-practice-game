## Description

Learning Git syntax and managing directory states can be incredibly abstract for beginners. The **Git practice game** makes it easy for the beginners to get the basics. 

The application walks users through a 4-level game:
1. **Level 1:** Workspace setup, navigation and git configuration
2. **Level 2:** Tracking changes, inspecting diffs and commits
3. **Level 3:** Creation of the branches, switching between them and solcing conflicts
4. **Level 4:** Sending changes to remote repository and getting them locally

As players type commands into a  terminal window, the application  matches their text against an expected input. Upon a successful match instructions are being updated and game continues.
